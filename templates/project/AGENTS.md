# Agent instructions for this project

This project was set up with the Build It Yourself Harness.

## At the start of every session
1. Read `SESSION-NOTES.md` (where we left off) and `CHECKLIST.md` (what's set up and where it lives).
2. Run `git pull`.
3. Show where things stand, name the next step, and ask if the person is ready to continue.

## While working
- After each finished step, tick it in `CHECKLIST.md`.
- When the person pauses or the session ends, update `SESSION-NOTES.md` (last finished, in progress, next step, decisions, open questions), then commit and push.

## Always
- Secret values stay in `.env`. Names only in any file that goes to GitHub.
- Ask before anything that sends, deletes, spends, or changes account settings.
